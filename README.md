# Weather Forecast (Python)

Open-Meteo APIを使用して天気予報を取得するPythonスクリプトです。

## 機能
- 都道府県名を入力して天気予報を取得
- 入力ミス時は再入力を促す処理
- 7日間の1日ごとの最高・最低気温と天気を表示
- 各日の1時間ごとの気温・天気を表示
- 天気コードを日本語表記に変換

## 使い方
1. Pythonファイルを実行
2. 表示される案内に従い、都道府県名を入力
3. 天気予報が表示されます

## 使用技術
- Python
- requests
- Open-Meteo API
